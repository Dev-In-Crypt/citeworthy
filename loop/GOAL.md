# GOAL.md — контракт цикла

## Конечное состояние

Все задачи в [../TASKS.md](../TASKS.md) отмечены `[x]`, кроме задач с пометкой `[H]` в live-режиме (они блокированы на человеке и выполняются в mock-режиме настолько, насколько возможно).

## Доказательство (proof)

Итерация считается успешной, только если ВСЁ из списка истинно:

1. Ровно одна задача из TASKS.md переведена из `[ ]` в `[x]` за итерацию.
2. Её verify-критерий (описан в самой задаче) исполнен и прошёл.
3. `pnpm typecheck`, `pnpm lint`, `pnpm test` — exit 0 (когда монорепо уже существует; для T00 — критерий самой T00).
4. Изменения закоммичены в git одним коммитом с сообщением `T<NN>: <краткое описание>`.
5. `loop/STATE.md` обновлён (что сделано, что дальше, блокеры).

Проверку выполняет отдельный верификатор (другой вызов модели, см. VERIFY_PROMPT.md), не автор итерации.

## Запреты

- Не нарушать инварианты [../CLAUDE.md](../CLAUDE.md) (tenancy, запрещённые слова, white-label, «не строить»).
- Не менять контракты C1–C6 в TASKS.md и не редактировать формулировки задач (только чекбоксы и Log).
- Не трогать файлы спеков (`startup-spec.md`, `AI Search Delivery OS for Agencies.md`, `ai-visibility-project.md`).
- Не делать больше одной задачи за итерацию, даже если «осталось чуть-чуть».
- Не ставить `[x]` без прохождения verify. Если verify не проходит — чекбокс остаётся пустым, блокер описывается в STATE.md.
- Никаких сетевых вызовов к платным LLM API в тестах (`ADAPTERS_MODE=mock`); live-ключи цикл не использует вообще.
- Секреты не писать ни в какие файлы.

## Бюджет и тормоза (enforced скриптом run-loop.ps1, не моделью)

- Потолок итераций: 25 за запуск скрипта.
- Потолок стоимости: $15 за запуск (сумма `total_cost_usd` по итерациям).
- Детект отсутствия прогресса: 3 итерации подряд без нового `[x]` и без нового коммита → стоп.
- Провал верификатора 2 раза подряд по одной задаче → стоп (человек разбирается).
